# issue #69：「PDF 逐字空格让结构锚点全灭」—— 我提的假说，被自己的量测否掉了

起因：#67 放量后 6 条没产出可核对要点，其中 `4815e769`（附件抽出 48,543 字）我上一轮记成
"未解释的个例"（`67-summaries-redraft.md` 第八节）。本轮去查它。
**结论：假说是错的，代码没有改；但顺带把那条"未解释"解释掉了。**

## 一、假说与其诱惑力

`scripts/audit-draft-window.mjs`（本轮新增，只读）把摘要任务**实际送进提示词的那一截**打出来：

```
窗口：《电力供应行业数字化转型场景图谱建设与实施指南》等196项行业标准制修订计划（征求意见稿）
      送入 7,974 字符 / 1,432 汉字；第X条 0 处，规范性字样 4 处
      开头：工 业 和 信 息 化 部 二 〇 二 六 年 第 十 八 批 行 业 标 准 制 修 订 计 划 …
```

7,974 字符里只有 1,432 个汉字 —— 八成预算花在空格与目录点线上，而窗口内容是封面 + 目录。
于是很自然地推出：**`STRUCTURE_ANCHORS` 与章节骨架都按连续汉字写（`适用范围`、`^第X章`），
`适 用 范 围` 匹配不上 ⇒ 锚点全灭 ⇒ `excerptForPrompt` 退化成"取前 8,000 字符"**。

这个链条每一步都讲得通，而且修法看起来干净（在截取前做一次空白归一）。**我按它写了实现**：
`normalizeDraftSpacing()` + 接到 `draftSourcesForSummary()` 里 + 5 条单测 + 2 条接线测试 + 2 个 pin。

## 二、量测把它否掉了

在生产库上对**全部 75 个有正文的附件**跑一遍"去掉空白后再找锚点"（判据：
`适用范围 / 本文件适用于 / 第一条 / 第二条 / 第一章`）：

| 指标 | 实测 |
| --- | --- |
| 原样就能找到锚点的文件 | **42** |
| 去掉空白后才找得到锚点的文件 | **42**（比原样**多 0 个**） |
| 两种写法都没有锚点 | 33 |
| 平均被去掉的空白字符 | 1,970（最差一份 20,033） |

`newly_unlocked = 0`。也就是说逐字空格只出现在**封面与标题行**（`工 业 和 信 息 化 部`），
没有出现在锚点短语内部 —— 我拿一条被空格毁掉的*标题*去推断"锚点全灭"，推断过头了。

而 `4815e769` 那份 48K 字的文件**两种写法都一个锚点都没有**：它是 196 项标准的
**项目计划表**，不是一份有规范性条文的草案。所以它和另外 5 条属于同一类
（三份委员名单、两份立项申报书、一份计划表、一份计划表性质的指南）——
**上一轮登记的"未解释个例"到此解释完了：不是截取窗口的问题，是附件里没有条文。**

## 三、没有发布的那半边收益，与为什么不做

空白归一仍然有 measurable 的一半：同样的 8,000 字符预算平均能多装约 2K 字符的正文
（最差一份 20K）。但不做的理由更硬：

1. **没有产出侧的证据**。锚点一条都没复活，被去掉的是标题里的空格与目录点线；要宣称
   "摘要会更好"必须实测，而我手上只有"窗口更干净"这个中间量。
2. **它弱化页面上那句话的含义**。摘要的引用是从**喂进去的文本**里逐字挑的（`buildQuotedSummary`），
   改了输入形状，详情页「本站从附件逐字提取，未做改写」里的"逐字"就变成"逐字（去空格后）"。
   为一个没证明的收益去动一句诚实声明，不划算。
3. **代价落在一付费的外部通道上**。输入层任何改动都要靠重跑条目才能验证，那就是几十次境外调用。

判据留在仓库里（`deploy/audit-attachments-leftover.sql` 第 7 段、
`deploy/audit-redraft-state.sql` 第 9 / 10 段），将来出现"某份真有条文却被空格挤掉"的实例，
可以直接重测再决定。

## 四、这一轮顺手记下的两件事实

- **e2e 抓到了我的一次真回归**：第一版把 `\n` 也当分隔符折叠，整篇正文被缝成一行，
  stub 按行取条文于是不再命中，`summary-draft-input` 与详情页分支两条断言当场红。
  红得对 —— 那正是「条目结构是锚点判据的前提」这件事没被写下来的漏洞。
- **不要把"看起来讲得通的因果链"当结论**。本例里链条的每一环都真（确实有逐字空格、
  确实窗口被点线占满、确实锚点要连续汉字），合起来的推论却是假的。唯一有效的是那一条
  `newly_unlocked = 0`。这条与迭代 3（放宽版本链只会造出 0 条链）、附件文件名进检索
  （比错分母量出 51.8%）是同一族教训：**能一行 SQL 判死的事，不要先写实现。**
