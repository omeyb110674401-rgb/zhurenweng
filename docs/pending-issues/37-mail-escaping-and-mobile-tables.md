## 缺陷 1：邮件 HTML 正文的动态值全部未转义

`src/lib/mail.ts` 的 `html` 部分是手工拼的字符串，插进去的动态值没经过任何转义，
三个来源都不可信：

1. **订阅关键词**（公开表单）：任何人可以用**别人的邮箱**提交带 HTML 的规则，
   收件人收到的确认邮件里就会渲染攻击者控制的标签与链接 —— 钓鱼面；
2. **错误摘要**（告警邮件 `<pre>`）：抓取失败的原始报文，可能含 `<`；
3. **条目标题 / 截止日期**（提醒邮件）：来自源站，标题里出现 `&` 只是时间问题
   （feed 那边就为 `&` / `<` 专门加过用例）。

修法：新增 `escapeHtml()` 并应用到全部 7 处 HTML 插值；**纯文本部分不转义** ——
用户在那里应看到字面内容，转义反而会让「关键词：a&b」变成「a&amp;b」。

## 缺陷 2：统计页宽表在窄屏撑破整页

趋势表 8 列，`.stat-table { width: 100% }` 且没有任何滚动容器，min-content 宽度
远超手机视口 → 表格把**整页**撑出横向滚动条（页头页脚跟着被拖走）。

修法：两张表各包一层 `.stat-table-wrap`（`overflow-x: auto`），并加 `role="region"` +
`tabIndex={0}` —— 纯 overflow 容器不可聚焦，键盘用户滚不动这块区域；
`.stat-table-wrap:focus-visible` 给可见焦点环。表格**不设 min-width**：趋势表按
min-content 宽度溢出滚动，部门表在手机上仍自然铺满。

## 验收

- 新增 `tests/unit/mail-html.test.mjs`（3 条）：确认邮件关键词、提醒邮件标题与截止日期、
  告警邮件错误报文都被转义，且自家标签与纯文本部分保持原样。**red→green 已验证**：
  把 `escapeHtml` 改成恒等函数后 3 条全红（「HTML 里不应出现原始标签」），还原后全绿。
- 统计页 e2e 新增 1 条：两张表都在可聚焦的滚动容器里，且**读 `globals.css` 断言
  `overflow-x: auto` 规则存在**（容器没有这条规则就等于没修）。
- 线上核验：2 个滚动容器、`role="region"` 与 `tabindex="0"` 齐备；构建产物 CSS 里
  确实有 `.stat-table-wrap{-webkit-overflow-scrolling:touch;border-radius:8px;overflow-x:auto}`；
  全站页面 200。
- 本地：单元 106 + E2E 164 全绿，typecheck / lint 干净。
